Tinker Lab teaches electronics, Arduino, IoT, robotics and edge AI from first principles. You build circuits in 3D, write real code and watch it run, then take it to real hardware when you are ready.

Every lesson is a small project.
You wire it, you code it, you see why it works.

  • A bench in 3D

    Boards, breadboards, wires and parts you can turn, zoom and click. Press the button, turn the knob, cover the light sensor and see what changes.

  • Real code

    Arduino C++, MicroPython and Python, written the way you would write it for a real board. Change a number and run it again.

  • Explained from the start

    What a resistor does, why the LED needs one, what each line of code means. No step assumes you already know the trick.

Curious kidsMake an LED blink before you own one.

The first tracks need no board and no code. Pictures, animations and things to click come first. A grown-up nearby helps, especially when the real parts come out.

StudentsGo from Ohm's law to Wi-Fi sensors.

The tracks climb from basic circuits to interrupts, I²C, MQTT and neural networks on a Jetson, with quizzes and challenges along the way.

TeachersShow one circuit to a whole class.

For educators

MakersTry the wiring before you solder.

Check a pinout, test a sketch and see how a sensor behaves before you buy it. Then take the build guide to the bench.

Four steps,
in the same order every time.

  1. Learn

    Read a short explanation with drawings. Each idea comes with a part you can touch.

  2. Build

    Wire the circuit on a 3D breadboard and watch where the current goes.

  3. Code

    Read the real program, change it and run it. Step through it line by line if you like.

  4. Take it to hardware

    Print the build guide, pick up the parts and build the same thing on your desk.

The simulation is a teaching model, not an exact copy of the hardware. It is close enough to learn from, and we say where it differs. How the simulation works

What we believe

We think anyone can understand how a circuit works if it is shown clearly and explained in plain words. Nobody should have to buy a kit, make an account or hand over their data to find out whether they like it.
