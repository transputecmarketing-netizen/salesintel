      How it works

      Wire it. Code it. Run it.

      Every lesson is a working circuit you can explore from any angle, with real code you can tweak and run — then copy straight into the Arduino IDE, Thonny or your Jetson.

      1. 01

        Wire it

        See exactly where every jumper goes on a 3D breadboard. Click parts to inspect them, turn knobs, press buttons, swap resistor values.

      2. 02

        Code it

        Real, compilable C++ and Python with every line explained. Change the numbers in the code and watch the circuit respond.

      3. 03

        Run it

        Hit run to simulate the sketch: LEDs light, motors spin, the serial monitor talks back, and current flows along the wires.

      4. 04

        Prove it

        Each lesson ends with a quiz and three challenges, so you know you understand it — not just that you watched it.

      FAQ

      Questions, answered

      Do I need any hardware?

      No. Everything runs in the browser. If you want to build a lesson for real, the Wiring tab lists every connection and the code copies straight into the Arduino IDE, Thonny or a Python file on the Jetson.

      Is it really free?

      Yes. There is no account, no paywall and no tracking of your progress on a server — it’s saved in your own browser.

      Is the simulation exact?

      It’s a teaching simulation: it follows the program line by line and models what the parts do (brightness, angles, distances, readings) closely enough to learn from. Real hardware adds noise, timing quirks and wiring mistakes — which is why every lesson also explains the real-world details.

      Which boards are covered?

      Uno-style boards, the Mega 2560 and Nano, the ESP32 (Wi-Fi and Bluetooth), the Raspberry Pi Pico with MicroPython, and the Jetson Nano for GPU-accelerated computer vision.

      What age or level is it for?

      The Foundations track assumes no prior knowledge and suits curious beginners from about age 11 up. Later tracks reach university and professional topics such as interrupts, communication buses, MQTT and neural-network inference.

      Does it work on phones and tablets?

      Yes. The layout adapts to small screens and you can drag, pinch and tap to explore the 3D view. A larger screen is more comfortable for reading code.
