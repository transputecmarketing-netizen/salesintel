What to write about.
Anything that helps the next learner.

  • Something is wrong

    A wrong value, a wire in the wrong hole, code that would not compile on a real board. Tell us the lesson and what you saw. A screenshot helps.

  • Something is hard to use

    If a page does not work with your screen reader, keyboard, browser or device, we want to know.

  • Using it with a class

    Questions about lessons, levels or fitting Tinker Lab into a course. Our educators page may already answer them.

  • An idea for a lesson

    A sensor you want explained, a board you want to learn on, a project you want to build.
