Blue Cap Mascot

Your sketch, traced to SVG and rigged head to toe, moving on Hairline's two clocks: near-critical springs for anything that follows you, a 700 ms lift curve for every change, staggered joint by joint. Real shoulders, elbows, wrists and fingers, legs that bend at the knee, a jaw that drops when he talks. Left alone he breathes, blinks, shifts his weight and glances around; click him and he laughs.

Agent hooks

Agents drive him through ten MCP tools. The same calls work three ways: in the page with rig.call(name, args), from a parent window or extension as JSON-RPC over postMessage after rig.listen(), or from any MCP client through mcp-server.mjs.

<script src="/mascot/mascot.js"></script>
<script>
  const buddy = Mascot.mount(document.getElementById("buddy"));
  buddy.express("happy");            // smile, neutral, happy, laugh, surprised, sad, thinking, shy, sleepy, angry
  buddy.gesture("wave", { hold: 3 }); // wave, hello, hi5, idea, count2, thumbsUp, point, think, cheer, shrug, belly, explain, shy, none
  buddy.setView("bust");             // or "full"
  buddy.say("Ready for five quick questions?", { speak: true });
  buddy.lipSync(audioElement);       // or buddy.setMouthOpen(level) from your own TTS stream

  // Agent hooks
  await buddy.call("mascot_set", { params: { "mouth.open": 0.5, "hand.right.shoulder": 30, "hand.right.index": 0.2 } });
  buddy.on("state", (s) => console.log(s.expression, s.params["mouth.smile"]));
  Mascot.connect(buddy, "http://localhost:4545"); // relay for: node public/mascot/mcp-server.mjs
</script>
